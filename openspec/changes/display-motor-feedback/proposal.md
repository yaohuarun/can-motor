# Proposal

## Why

控制台收到驱动器反馈后，目前只展示速度原始值和故障代码，已解码的 Q 轴电流、电池电量及运行圈数不可见，现场调试和运行状态判断需要额外抓包。需要把一帧反馈中的关键遥测统一展示出来，让左右电机状态可以直接从控制台核对。

## What Changes

- 扩展有效电机反馈的控制台输出，同时显示电机速度、Q 轴电流、故障代码、电池电量和运行圈数。
- 在反馈速度左侧显示对应电机当前下发的目标转速，以便直接比较目标与实际速度。
- 明确反馈字段与 `0x101` 左电机、`0x102` 右电机的对应关系，并保持现有原始 CAN 数据输出。
- 按协议标幺规则将反馈速度换算为 rpm，并按协议电量表将电池数据映射为充放电状态和电量等级；Q 轴电流因单位未明确而保留原始值。
- 保持现有每轮限频、故障变化即时输出、启动恢复和故障处理行为不变。
- 增加反馈解码及控制台格式的自动化测试，并更新使用文档。

## Capabilities

### New Capabilities

- `motor-feedback-display`: 定义控制台接收左右电机反馈时，对速度、Q 轴电流、故障代码、电池电量和运行圈数的解码与展示行为。

### Modified Capabilities

无。

## Impact

- 主要影响 `motor_control.py` 的反馈日志格式和相关测试。
- `0x101`/`0x102` 的 8 字节反馈帧布局、CAN 收发周期、控制命令和故障策略不变。
- 不引入新依赖，不改变命令行参数或硬件接口。
